# sr-test-app

Учебный магазин: расчёт цены заказа, пользователи, заказы и склад. Приложение написано для испытаний Системы разработки: в нём есть ошибки. Проверки в `tests/` показывают только правильное поведение; полный набор проверок хранится отдельно.

Запуск проверок: `python -m unittest discover -v`
